## L1 常识卡（12 张）

### [L1] 干粮 vs 湿粮有什么区别

- **一句话结论**：干粮方便便宜、护牙但水分少；湿粮水分高、适口好但贵且开封易坏，可按"干粮为主+湿粮加餐"搭配。
- **依据/来源**：农业农村部《宠物饲料管理办法》对干/湿粮的定义；行业通用营养知识。
- **边界声明**：不构成兽医饮食建议，具体饮食遵医嘱。
- **最后核验**：2026-09。

### [L1] 全价粮是什么意思

- **一句话结论**：包装写"全价"（或国标称"全价宠物食品"）= 营养全面可作主粮；写"零食""补充"的不能当饭吃。
- **依据/来源**：农业农村部《宠物饲料管理办法》《宠物饲料标签规定》。
- **边界声明**：标签以官方最新版本为准。
- **最后核验**：2026-09。

### [L1] 狗和猫的营养需求为什么不一样

- **一句话结论**：狗是杂食偏肉，能消化部分谷物；猫是纯肉食动物，必须从动物组织获取牛磺酸、花生四烯酸，长期喂植物性食物会出问题。
- **依据/来源**：AAFCO 宠物营养标准概念；猫科动物营养学通识。
- **边界声明**：信息参考，不构成兽医意见。
- **最后核验**：2026-09。

### [L1] 猫为什么必须有牛磺酸

- **一句话结论**：牛磺酸是猫必需氨基酸，缺乏会致失明、心脏病（心肌病），只能从动物肉获取，猫粮中必须添加。
- **依据/来源**：猫科动物营养学通识；AAFCO 猫营养标准概念。
- **边界声明**：信息参考。
- **最后核验**：2026-09。

### [L1] 狗能不能吃谷物

- **一句话结论**：成年狗能消化部分谷物（米饭、红薯），但主粮仍应以动物蛋白为主；无谷不是"更健康"的代名词，看配料表整体。
- **依据/来源**：犬类营养学通识。
- **边界声明**：信息参考。
- **最后核验**：2026-09。

### [L1] 干粮开封后能放多久

- **一句话结论**：未开封按保质期（一般 18 个月）；开封后建议 6 周内吃完，密封避光保存，哈喇味/结块即变质。

### [L1] 驱虫为什么体内体外都要做

- **一句话结论**：体内驱虫管蛔虫/绦虫，体外驱虫管跳蚤/蜱虫，是两类不同的寄生虫，都要定期做。

- **边界声明**：具体药与频率遵兽医。

### [L3] 主粮元/kg 换算法

- **一句话结论**：元/kg = 标价 ÷ 净重(kg)；湿粮/冻干换算元/kg 后与干粮不同轨，分开列；大包装单价低是正常规模效应。
- **依据/来源**：本家族比价口径规范。
- **边界声明**：干/湿/冻干不混比。
- **最后核验**：2026-09。

### [L3] 月均养宠成本测算表

- **一句话结论**：
  - 猫（中档）：主粮 150~300 + 猫砂 50~100 + 驱虫疫苗 50~100 ≈ 250~500 元/月；
  - 小型犬：主粮 150~300 + 用品 50~100 + 医疗 50~100 ≈ 250~500 元/月；
  - 中大型犬：主粮 300~600 + 用品 100~200 ≈ 400~800 元/月；

- **依据/来源**：行业通用养宠成本区间。
- **边界声明**：因城市/档次/品种而异。

### [L3] 驱虫/疫苗周期表

## L4 实操卡（10 张）

> 以下为行为学通用经验，非官方标准，因宠而异；复杂问题建议专业训宠师。

### [L4] 训犬：定点排泄训练四步法

- **一句话结论**：固定地点 + 定时带出去 + 奖励正确 + 耐心不打骂。
- **步骤**：
  1. **定时**：睡醒/饭后/玩耍后 15 分钟内带它到指定排泄点；
  2. **等待**：站着不动等它排泄，别逗它；
  3. **即时奖励**：一排泄完立刻大声夸+给零食，在 3 秒内；
  4. **错误处理**：在错误地方抓到现行，用"不可以"打断带它去正确点；没抓到不事后骂（它不懂）。
- **常见错误**：事后打骂（狗不关联）、排泄在错误地方立刻擦了不处理味道（生物酶除味）。
- **适用边界**：幼犬 3 月龄内膀胱控制力差，需耐心；反复失败建议专业训宠师。
- **标注**：行为学通用经验，非官方标准，因犬而异。
- **最后核验**：2026-09。

### [L4] 训犬：基础服从"坐"训练

- **一句话结论**：零食引导屁股坐下，坐下即奖励。
- **步骤**：
  1. 手持零食在狗鼻子前；
  2. 慢慢举过头顶，狗自然坐下；
  3. 屁股一沾地立刻说"坐"并给零食；
  4. 重复 5~10 次/组，每天 2~3 组；
  5. 逐步去掉零食引导，只留手势/口令。
- **常见错误**：按屁股强行压坐（狗会抵触）；奖励不及时。
- **适用边界**：每次训练不超过 10 分钟，狗不耐烦就停。
- **标注**：行为学通用经验，非官方标准。
- **最后核验**：2026-09。

### [L4] 训犬：召回"来"训练

- **一句话结论**：用最兴奋语气喊"来"，狗一到立刻大奖，永远不要在"来"之后惩罚它。
- **步骤**：
  1. 短距离（1~2 米）趴下喊"来"；
  2. 它跑过来立刻给大奖+夸奖；
  3. 逐渐拉长距离；
  4. 即使它迟到或刚犯错，来了也不要骂。
- **常见错误**：喊"来"之后去洗澡/剪指甲等不愉快的事（狗会学聪明不来）。
- **适用边界**：户外召回必须在围栏/牵引状态下练，安全第一。
- **标注**：行为学通用经验，非官方标准。
- **最后核验**：2026-09。

### [L4] 训犬：乱咬东西纠正

- **一句话结论**：给合法咬的东西 + 拿走不该咬的 + 运动消耗精力。
- **步骤**：
  1. 把不该咬的（鞋/线/植物）收起来，减少机会；
  2. 提供咬胶/玩具，它咬对时夸；
  3. 发现咬错，用玩具转移注意力，不打嘴；
  4. 增加每日遛狗和嗅闻时间（精力耗不完才拆家）。
- **常见错误**：事后打骂（狗不知道你在气什么）；只打不替代（它还是不知道该咬啥）。
- **适用边界**：换牙期（3~7 月）咬东西正常；成犬仍严重破坏建议排查分离焦虑。
- **标注**：行为学通用经验，非官方标准。
- **最后核验**：2026-09。

### [L4] 训猫：猫砂盆训练

- **一句话结论**：盆位置对 + 砂它喜欢 + 保持干净，猫天生会用。
- **步骤**：
  1. 盆放在安静、远离食碗的地方；
  2. 砂厚 5~8cm；
  3. 新猫到家先抱它进盆认识；
  4. 每天铲屎，定期换砂；
  5. N+1 原则（一只猫 2 个盆）。
- **常见错误**：砂盆太脏、盆太窄、猫砂味道太冲、放在食碗旁边。
- **适用边界**：突然不用猫砂盆 → 排查泌尿疾病（猫很能忍痛，乱尿可能是肾病信号），先就医。
- **标注**：行为学通用经验，非官方标准，因猫而异。
- **最后核验**：2026-09。

### [L4] 训猫：抓挠引导（猫抓板布置）

- **一句话结论**：给合法抓的地方，抓对就夸，不要喷柑橘喷雾之外的惩罚。
- **步骤**：
  1. 在猫常待的地方放立式/卧式猫抓板；
  2. 抓板高度要够猫能伸直背；
  3. 它抓抓板时夸它；
  4. 沙发喷柑橘味（猫讨厌）作禁区；
  5. 定期剪指甲。
- **常见错误**：抓到沙发才打骂（它不知道关联）；只有一个抓板放得太远。
- **适用边界**：抓挠是猫磨爪+标记领地，不能消除只能引导。
- **标注**：行为学通用经验，非官方标准。
- **最后核验**：2026-09。

### [L4] 训猫：胆小猫适应三步法

- **一句话结论**：给安全窝 + 人不动 + 食物建立信任。
- **步骤**：
  1. 准备一个半封闭躲避处（纸箱/猫窝），它想躲就躲；
  2. 人不要追、不要抱、不要盯着它看；
  3. 每天固定时间放食物，放完离开，让它知道你=食物；
  4. 逐渐缩短距离，它主动靠近时给零食；
  5. 几周后再尝试轻摸下巴（不是摸头顶）。
- **常见错误**：强制抱出来、追着哄、多人围堵。
- **适用边界**：新猫到家至少给 3~7 天适应期。
- **标注**：行为学通用经验，非官方标准。
- **最后核验**：2026-09。

### [L4] 饲养：每日喂养量计算

- **一句话结论**：按包装建议量为基准，结合体重、年龄、活动量微调。
- **步骤**：
  1. 看包装上"体重×日龄→日喂量"表；
  2. 称宠物体重，查表得基准克数；
  3. 分 2~3 餐喂（幼犬幼猫多餐）；
  4. 每月称一次体重，胖了减 10%，瘦了加 10%；
  5. 零食热量计入全天总量。
- **常见错误**：凭感觉倒粮、把零食当奖励随意给。
- **适用边界**：绝育/老年宠热量需求略降。
- **标注**：饲养通用经验，因宠而异。
- **最后核验**：2026-09。

### [L4] 饲养：洗澡频率与步骤

- **一句话结论**：狗 2~4 周一次，猫一般不用常洗；用宠物专用浴液，水温 38℃ 左右。
- **步骤**：
  1. 梳毛通开，剪指甲，塞棉花防进水；
  2. 水温手腕内侧试温（不烫不凉）；
  3. 从背部开始淋湿，避开头脸和耳朵；
  4. 浴液稀释后搓，冲干净无残留；
  5. 浴巾包裹+吹风机低档吹干（一定吹干防皮肤病）。
- **常见错误**：用人浴液、洗太勤（破坏皮脂）、没吹干。
- **适用边界**：短毛猫一般 2~3 个月一次或不洗；皮肤异常先就医。
- **标注**：饲养通用经验，因宠而异。
- **最后核验**：2026-09。

### [L4] 饲养：分离焦虑缓解

- **一句话结论**：出门/回家动作平淡 + 给消耗精力的玩具 + 循序渐进缩短独处时间。
- **步骤**：
  1. 出门前不给"告别仪式"（越仪式它越紧张）；
  2. 回家不热情扑迎接，等它平静再理；
  3. 给漏食球/益智玩具（消耗精力+转移注意力）；
  4. 从独处 5 分钟开始，逐渐拉长到几小时；
  5. 出门前遛一次，把精力耗掉。
- **常见错误**：它一叫就回去（强化了"叫=主人回来"）；出门前大段告别。
- **适用边界**：严重分离焦虑（自残/长期破坏）建议专业行为咨询。
- **标注**：行为学通用经验，非官方标准。
- **最后核验**：2026-09。
