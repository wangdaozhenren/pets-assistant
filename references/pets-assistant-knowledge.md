| 场景 | 平台顺序 | 说明 |

| 主粮（干粮/湿粮/冻干） | 京东 → 淘宝/天猫 → 拼多多 | 京东自营品质稳；天猫旗舰正品；拼多多价格低但注意临期/分装 |

## 二、计价口径（元/kg 归一）

### 2.1 干粮

- 标价 ÷ 净重(kg) = 元/kg；
- **净重 vs 毛重**：包装上"净含量"才是净重，含包装重量不算；
- 常见规格：1.5kg / 2kg / 2.5kg / 5kg / 10kg / 12kg，大包装单价更低是正常的。

### 2.2 湿粮/罐头

- 标价 ÷ 总克数(g) ÷ 1000 = 元/kg；
- 注意单罐克重（80g/170g/375g）× 罐数；
- 与干粮**不同轨**，不直接比元/kg，分开列。

### 2.3 冻干

- 标价 ÷ 净重(g) 换算元/kg；
- 冻干密度远高于干粮，元/kg 数值会很高，属正常；
- 与干粮/湿粮**不同轨**。

### 2.4 生骨肉/鲜粮

- 需冷链，价格含运费，注意保质期；
- 与以上都**不同轨**。

### 2.5 同轨比较条件

必须同时满足：同一品牌 + 同一配方系列 + 同形态（干/湿/冻干）+ 同规格量级，才同轨比元/kg。不同品牌不同配方不比元/kg，只列各自单价。

## 三、双规格标题防假低价

- 标题写"低至 ¥XX"但实际 SKU 是最小规格 → **必开卡核实**；
- 点进商品页选到用户要的规格，读真实价格；
- 列表时用真实规格的元/kg，不用"低至"价；
- 分装/散装粮注意"非原装"标注。

## 四、主粮规格识别

| 标注 | 含义 |
|---|---|
| 全价粮 | 营养全面可作主粮（国标《宠物饲料管理办法》称"全价宠物食品"） |
| 处方粮 | 需兽医处方，不列购买入口 |
| 零食/磨牙棒 | 不能作主粮 |
| 干粮/膨化粮 | 水分 ≤14% |
| 湿粮/罐头 | 水分 ≥60% |
| 冻干粮 | 真空冷冻干燥 |

## 五、宠物医院计价

- 按"项目单价 + 挂号费/诊疗费"分开列；
- 常见项目：疫苗（猫三联/狂犬疫苗）、驱虫（体内/体外）、绝育、洗澡美容；
- 比价时同项目同医院不同平台（美团 vs 到店）的价格分开列。

## 六、安全避坑

### 6.1 有毒食物（明确提醒）

巧克力、葡萄/葡萄干、洋葱/大蒜、木糖醇（口香糖/烘焙）、酒精、咖啡因、澳洲坚果、生面团——对猫狗有毒，知识卡中明确列出。

### 6.2 临期粮识别

- 包装生产日期 + 保质期（干粮一般 18 个月，未开封）；
- 开封后干粮建议 6 周内吃完；
- 临期粮价格低但注意储存条件，霉变粮（哈喇味/结块）不能喂。

### 6.3 低价主粮陷阱

- 配料表第一位不是肉而是谷物/淀粉 → 蛋白可能靠植物蛋白凑数；
- "肉粉"标注模糊（"肉类及其制品"）→ 来源不清；
- 价格远低于行业均价 → 警惕淀粉充蛋白。

## 八、进阶：每克蛋白成本口径

- **每克蛋白成本 = 粮单价(元/kg) ÷ 粗蛋白保证值(%)**：同样 50 元/kg，粗蛋白 32% 的粮（约 1.56 元/克蛋白）比粗蛋白 24% 的粮（约 2.08 元/克蛋白）更"值蛋白"。比价时在元/kg 之外，叠加"每克蛋白成本"，避免只看单价低而蛋白也低。
- **粗蛋白保证值**以包装"保证值"或检测报告为准，不是宣传页的"高蛋白"字样。
- **国产主粮检测报告查验路径**：优先看品牌是否公示第三方（如 SGS/谱尼）检测报告；可在品牌官网/旗舰店详情页、国家市场监管总局宠物饲料抽检公示中核对；无检测报告、配料含糊的产品降权。

## 九、按月养宠成本与保险

- **月度成本对比口径**：粮 + 猫砂/用品 + 疫苗摊提 + 驱虫 + （可选）宠物保险。猫与狗分开列（狗体型大，粮/疫苗/绝育费用通常更高）。
- **宠物保险比价**：平安、支付宝（蚂蚁保）、微信（微保）等均有宠物医疗险；比价时看"保费 vs 报销比例 vs 免赔额 vs 既往症条款"，示例价格以平台实时为准。
- **异宠（兔/龟/鸟）**：基础饲养成本远低于猫狗，但粮/环境（笼舍/UVB 灯/恒温）有专门要求；比价按其专属用品，不与猫狗粮混比。
